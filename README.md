# 🚗 Sistema de Controle de Estacionamento

Projeto acadêmico desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **Pontifícia Universidade Católica do Rio Grande do Sul (PUCRS)**, na disciplina de **Programação Orientada a Objetos**.

## 📌 Sobre o projeto

O Sistema de Controle de Estacionamento é uma aplicação desenvolvida em JavaScript, executada com Node.js, que simula o gerenciamento de um estacionamento.

O sistema permite cadastrar clientes, registrar entradas e saídas de veículos, calcular tarifas e consultar informações gerenciais.

## 🛠️ Tecnologias utilizadas

- JavaScript
- Node.js
- Programação Orientada a Objetos (POO)
- Arquivos CSV para persistência de dados
- Git e GitHub para versionamento

## ⚙️ Funcionalidades

- Cadastro e gerenciamento de clientes
- Registro de entrada e saída de veículos
- Consulta de veículos estacionados
- Cálculo de tarifas conforme a categoria do cliente
- Aplicação de descontos para clientes elegíveis
- Controle de saldo e pendências financeiras
- Validação de regras de estacionamento
- Relatórios gerenciais
- Salvamento e carregamento de dados em arquivos CSV
- Interface de interação pelo terminal

## 👥 Categorias de clientes

O sistema contempla diferentes categorias, incluindo:

- **Avulso:** cobrança conforme o período de permanência.
- **Estudante:** regras específicas de cadastro, acesso e cobrança.
- **Professor:** regras próprias de veículos cadastrados e utilização.
- **Empresa:** cobrança e controle financeiro conforme as regras da categoria.

## ▶️ Como executar

**Pré-requisito:** Node.js instalado.

1. Clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Execute o comando:

```bash
node src/TesteInterface.js
```

O menu principal será apresentado no terminal, permitindo a utilização das funcionalidades disponíveis.

**Observação:** os arquivos CSV de dados operacionais não são publicados neste repositório. A execução pode depender da criação desses arquivos pelo próprio sistema.
